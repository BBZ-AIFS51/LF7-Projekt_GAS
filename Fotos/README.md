# Fotos

Fotos vom echten Aufbau. Sie werden in der Dokumentation (Wiki und PDF) und in
der Präsentation verwendet.

## So kommen die Fotos hierher

1. Auf GitHub oben links den Branch **`claude/trusting-knuth-awmzj8`**
   auswählen (nicht `main`).
2. In diesen Ordner `Fotos/` wechseln → **Add file** → **Upload files**.
3. Dateien hineinziehen, Dateinamen wie in der Liste unten, **Commit changes**.

Die Originale vom Handy dürfen groß sein. Vor der Verwendung werden sie
verkleinert (max. 1600 px, wenige hundert KB) und die **Metadaten entfernt**.
Handyfotos enthalten oft den GPS-Standort, und das Repository ist öffentlich.
