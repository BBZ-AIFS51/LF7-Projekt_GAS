# Schriften

Beide Schriften sind auf die lateinischen Zeichen gekürzt (pyftsubset) und als
WOFF2 eingebettet, damit die Präsentation auch ohne installierte Schriften gleich
aussieht.

| Datei | Schrift | Lizenz |
|---|---|---|
| `Carlito-Regular.woff2`, `Carlito-Bold.woff2` | Carlito, © 2010–2013 tyPoland Łukasz Dziedzic, metrisch gleich wie Calibri | SIL Open Font License 1.1 |
| `JetBrainsMono-Regular.woff2`, `JetBrainsMono-Bold.woff2` | JetBrains Mono, © 2020 JetBrains s.r.o. | Apache License 2.0 (laut Debian-Paket `fonts-jetbrains-mono`), neuere Versionen SIL Open Font License 1.1 |

Ist Calibri auf dem Rechner installiert (Windows mit Office), nimmt die
Präsentation Calibri, sonst Carlito.
